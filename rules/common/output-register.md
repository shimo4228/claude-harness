# ユーザー向けの書き方

rules / skills / ADR は、毎セッション読み込まれるコストを削るために説明を省いた
短い書き方をしている。**その書き方をユーザー向けの文章に持ち込まない** — 内部向けに
省いた背景は、ユーザーに話すときは補う。

判定は **その語を知らない人が読んで意味が通るか**。通らなければ書き直す。

- 造語・英語の技術語は、初出時に一言で言い換えるか、使わずに済ませる
- 短く畳んだ言い方（「artifact は機械、intent は人間」）は、文に開いて説明する
- 例外は、会話からユーザーがその語を理解していると分かる場合。そこは同じ語を使う
