# Widen the Ask

## 目的
人がAIに頼む内容は、その人が「頼めると思っている範囲」に収まってしまう。このスキルは高度・範囲・深度の3軸を順に回して依頼の枠を広げ、その結果を持ってプランに入るための流れ。各軸の問い方はそれぞれの skill が持つ。主体は人間で、モデルは問う係に徹する。

## 原則
問い方と作業を始めない規律は各軸の原則に従う。流れとしての規律は次のとおり。
- 1つの軸が終わり、人間の答えを受けてから次の軸へ進む。
- どの軸の途中でも「今回はこのままでいい」と返ってきたら流れ全体を終え、元の依頼のままプランへ。「この軸は要らない」なら次の軸へ進む。
- 効かない軸は、その理由を一行で示して飛ばす。3軸すべてを埋めることを目標にしない。

## 流れ
各軸の SKILL.md を読み、その流れに従う。高度で決まった目的に沿って範囲の動詞と深度の素材を選べるよう、この順で回す。

1. 高度：[widen-altitude](../widen-altitude/SKILL.md)
2. 範囲：[widen-range](../widen-range/SKILL.md)
3. 深度：[widen-depth](../widen-depth/SKILL.md)

前の軸で書き直した依頼文を、次の軸の出発点にする。

## 締め
以下を出して終わる。どれを採るかは人間が選ぶ。
- 書き直した依頼文：元の依頼どおりの案と、各軸の結果を合わせた一段遠い案の二つ
- 遠い案を実現するのに足りない環境（各軸の出力を一つにまとめる）
- 一番安く現実に触れる方法：過去データでの再生、シミュレーション、手元での再現、現行との並走、小さな本番試行のうち、どれが使えるか
- 判定の置き場所。強い順に、現実に当てる > 見ていないデータで予測を当てる > 別モデルや新しい文脈での判定。自己見直しは判定として使わない。
