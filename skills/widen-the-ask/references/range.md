# 範囲（range）

## 目的

名詞で書かれた依頼は、解決策の形についての本人の推測で、モデルの探索をその枠に閉じ込める。依頼を動詞に戻し、その動詞を本業にしている複数の分野のやり方と道具を持ち込む。

## この軸の原則

- 分野は役名ではなく「やる行為」で示す（例：「空売り投資家として」ではなく「空売り投資家がやるように、崩れる前提を探す」）。役を演じさせると会話が不自然になり、成果が上がらない。

## 流れ

### 1. 名詞を動詞に

依頼を動詞で言い直して示し、合っているか確認する。外れていたら、人間の答えを入れて言い直し、もう一度確認する。例（illustrative）：

- 「カレーのレシピ」→「平日の夜に、子どもが自分から野菜を食べたくなるようにする」
- 「四半期レビュー資料」→「忙しい人に因果の物語を信じさせ、不確実な中で判断させる」

### 2. 分野を挙げる

分野と、それぞれの行為を一行ずつ示し、人間に足し引きしてもらう。道具はまだ出さない（分野が確定してから調べる方が、人間の目が先に入る）。

- 外の分野（2〜3）：動詞を本業にしている分野。名詞の枠の外にあるやり方を持ち込む（例：ジャーナリストは一つの物語に絞って裏を取る、編集者は削って順番を決める）
- 本拠の分野（1）：元の名詞（成果物の形）を本業で作っている分野。その形を今作るのに使われている道具の揃え方を持ち込む（例：依頼が「動画」なら、AI で動画を作っている人）。この分野の一流の素材と検証を掘るのは深度の軸
- 壊す側（1〜2）：結果を崩しにいく分野（例：法廷会計士は数字の出所を辿る、懐疑的なレビュアーは採用されない理由を先に探す）

### 3. 道具を調べ、届くかを確かめる

人間が確定した分野ごとに、その行為に今使われている道具（ソフト、サービス、データ源、エージェント向けの skill・MCP・agent）を、SKILL.md の「道具と足りない環境」に従って調べ、届くかを確かめて分ける。入れれば使える道具は、入れずにモデルが用意できるものへ回す。

## 出力

- 持ち込む行為と道具を織り込んで書き直した依頼文。形の例（illustrative）：
  「〈動詞〉。〈外の分野〉がやるように〈行為〉を〈道具〉で行い、〈本拠の分野〉の〈道具〉で形にする。〈壊す側〉がやるように〈行為〉で崩す。分野ごとに別の agent で並列に回し、結果を突き合わせる」
- 分野ごとの行為と道具（道具には調べた日付と出所）
- 足りない環境：モデルが用意できるもの / 人間に頼むもの
