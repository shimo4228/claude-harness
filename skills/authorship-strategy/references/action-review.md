# Action review

具体案の採用・実施を検討するときに、関係する条件だけを確認する。
戦略上の選好との不一致と、実際の行動に必要な権限・条件を分けて説明する。

## 目的と実現性

案が誰にどんな価値を届けるか、そのために何が必要かを確認する。
現在の外部サービスや制度に依存する場合は一次情報で条件を確かめる。
効果が未検証なら、その点と、小さく試して何が分かるかを示す。
既存の実施状況や他作品との重複は、判断に関係するときに調べる。

## 出典と成果物

- 著者・出典・prior art を正確に扱う。受領、掲載、第三者による採用、効果の確認を混同しない。
- DOI や構造化 metadata は、その成果物の利用経路に必要な場合に使う。
  文献を取り込むときは一次出典を確認し、graph を編集する仕事なら対応する出典関係も整合させる。
- 現在の framework は再利用と公開アクセスを重視する。候補の license やアクセス条件が
  その目的にどう影響するかを説明する。異なる方針を選ぶ案には、その理由と tradeoff を示す。

## 外部への行動

- 投稿、連絡、登録、公開は、その行動へのユーザーの承認範囲で行う。
  案を話し合うことから、送信や公開の承認を推定しない。すでに承認済みの行動は繰り返し確認しない。
- 個人情報を必要とする手続きでは、本人が提供した必要な情報を使う。
- 本 framework の著者自身の活動では、community 統治の authority record に自分や
  自分の成果物の entry を self-create する行動は行わない（ADR-0021）。制裁回避の別アカウントや代理登録も用いない。
  この境界を、通常の対話・共同制作・正当な寄稿や紹介へ拡張しない。別の著者への適用では、
  その著者の方針と掲載先の現行規約を確認し、この事例から一律の禁止を導かない。
- 外部書き込みで rate limit が連発したら停止して報告する。制限を迂回する burst を続けない。
- 他者の collection に掲載するときは、許諾、正本の所在、再配布と撤回の条件を確認する。
  現行方針は link-index 型を優先する（ADR-0012）。別の方式は条件と方針変更を具体的に検討する。
- 著者の現在の非収益方針を前提とした実施では、商業サービスを経路に使うことと、
  著者が収益を得ることを区別する。個人的な制約の理由を公開資料へ転記しない。

## 実施後の記録

適用先が定める private ledger を先に更新し、public timeline があれば日付付き介入だけを
投影する。公開記録には私的な運用詳細を入れず、介入した事実から効果を主張しない（ADR-0014）。
