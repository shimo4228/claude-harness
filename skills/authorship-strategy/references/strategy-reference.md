# Strategy reference

既存 framework を説明・検討するときの背景資料。以下は現在の戦略上の仮説と選好であり、
探索で満たす条件ではない。詳しい判断と来歴は
[doctrine repository](https://github.com/shimo4228/authorship-strategy) の thesis・ADR・glossary にある。

## 作り手の目的

考えを作り、使われ、出典をたどれる形で残す。DOI、論文、機械可読 metadata はそのための道具。
読み手には実務者、開発者、学習者、creative reuser も含まれ、学術引用は接点の一つ。
何を残したいか、誰に役立ちたいかは、著者が現在の会話で見直せる。

## 三つの反転

| 軸 | この framework の選好 |
|---|---|
| 価値の根拠 | 希少性より、考えが広く使われること |
| 妥当性の読み方 | 独占より、派生や再利用が生まれること |
| 広がり方 | 囲い込みより、アクセスと再利用を開くこと |

これらは戦略の主張であって、公開すれば出典が必ず保存されるという実証結果ではない。
公開、再利用、著者名への帰属は、それぞれ別に確かめる必要がある。

## 四つの判断の観点

- **Authenticity**: 著者が大切にしていることと、成果物・行動の関係。
  framework が著者に代わって「本物」を定義することはできない。
- **Attribution diffusion**: 考えが届くことと、出典が残ること。
  モデルの学習を経た伝播と、検索・取得による参照では経路も確認方法も違う（ADR-0008）。
- **Idea / scaffold**: 残したい判断と、それを今実行するための一時的な手段の区別。
  この区別そのものの前提も検討できる。
- **Tactics**: 出典情報、公開形式、再利用のしやすさ、読み手との接点など、目的に応じた手段。
  戦術 catalog は過去の選択肢であり、候補を尽くす分類ではない。

## Audience と観測

従来の運用では、doctrine 層は LLM-mediated な経路と長期的な再利用、essay 層は
同時代の読者への届き方を分けて見ている（ADR-0022）。この区分は数値の混同を避けるためのもの。
LLM 経由を主軸にすることや、従来の成功指標が今の目的に合うかも問い直せる。
過去の traffic や単発のモデル応答は、それだけで効果の証明にならない。

## 出典をたどれる形にする

識別子、著者情報、既存文献との関係、具体的な実装例は、考えの所在や来歴を理解する助けになる。
固有用語を増やすこと、配信先を増やすこと自体は目的ではない。由来や効果を推測で補わない。
具体的な provenance 編集を依頼された場合の参考は [provenance task prompt](../provenance-layer-prompt.md)。
