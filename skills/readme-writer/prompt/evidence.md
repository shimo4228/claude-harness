> LLMは文脈が不足しているわけではない。むしろ文脈を持ちすぎているから、過剰なまでに情報を詰め込んでしまう。一方で、読む人がどんな人たちでこれまでにどんなやりとりをしたかという限定された文脈をもっていない。

> そういう意味ではLLMはコモンセンスを大量に持ち合わせているが、あまりにも持ちすぎているため、言わなくてもわかるところまで補足してしまうわけか。
