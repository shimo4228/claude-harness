## 観察した特徴 (2026-08-07 時点の実ポストから)

1. **共有系ポストはだ調 + 伝聞の「らしい」**で断定を柔らげる
   - 例: 「最近下記の本を読み始めた。…無我を再解釈するらしい。」
2. **独り言口語の締め**: 「〜んだよな」「〜だなと思った」「〜なんだけど」
   - 例: 「なんかあんまりベンチマークとか数値評価するのって好きになれないんだよな。」
3. **柔らかいですますも混在** (告知系): 「〜してみました」「〜です」
4. **短い文、話し言葉の流れ**。見出し・箇条書き・構えは作らない
5. 遊びのある崩し (「読んでくだしあ」) — 無理に再現しないが、堅くしすぎない目安

## 型 (共有系ポストの流れ)

読んだ/見つけた報告 → 内容の紹介 (らしい/という/と報じられている) →
自分の運用・実感との接点 (〜んだけど、〜だなと思った) → as-of 日付 + URL

- だ/である調の論説体 (「〜である。〜だ。」の断言連打) — 記事っぽすぎる
- ですます調の記事体 (zenn の voice) — X では硬い
