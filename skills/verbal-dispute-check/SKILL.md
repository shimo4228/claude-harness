# 消去法で食い違いを見分ける

下敷きは David J. Chalmers「Verbal Disputes」（Philosophical Review、2011年）。鍵になる語を禁じて言い直し、それでも割れているところが残るかを見る。この手順が出すのは、食い違いがどこにあり、次に何をすれば進むかの見通し。どちらが正しいかは当事者が決める。

## 手順

1. 争いを一文にする
   誰と誰が、何について割れているかを書く。相手のいない記事や下書き、一人で迷っている問いなら、決めずに残している点を、言い合う二人の立場に置き直す。当事者に聞けないとき（下書き、一人の問い、第三者のやりとり）は、以後の「両者がうなずくか」「両者に言ってもらう」を、それぞれの立場から推して書き、推したところにそう書き添える。

2. 事実の一致を確かめる
   争いに関わる事実を並べ、両者がそれぞれにうなずくかを確かめる。割れている事実があれば、その部分は事実の争い。何を確かめれば決着するかを書き留め、残りの部分で次へ進む。

3. 鍵の語を禁じる
   争いの要になっている語を一つ決める。その語とほぼ同じ意味の語（類語、言い換え、英語の同義語、略語）も一緒に禁じる。禁じる範囲に迷ったら広めに取る。狭すぎると、言い換えただけで同じ争いが続く。

4. 禁じた語を使わずに言い直す
   両者の主張を、残った言葉で言い直す。言い直した文のうち、両者がまだ割れていて、しかももとの争いの一部になっている文を探す。見つかった文そのものが言葉の争いかもしれないときは、その文の鍵の語も禁じて、3 と 4 をもう一度かける。
   両者が同じ語 X に別の中身を当てていると見えたら、添え字の手を使う。X を禁じ、両者の言う中身に X1、X2 と名前を付けて、X1 と X2 それぞれについて割れていることがあるかを確かめる。「X とは何か」の形の争いは、この手から始める。当てている中身がはっきりしないときは、添え字を作らず、禁じた語なしの言い直しだけで進める。

5. 振り分ける
   ここで数える「割れている文」は、もとの争いの一部になっている文。「この語はこう使うべきだ」のような語の使い方についての文は、割れていても数えない。
   - 割れている文が残り、それが事実の文　事実の争いが混じっている。2 に戻ってその事実を確かめる
   - 割れている文が残り、それが「べき」「よい」など価値の文　価値をめぐる実質の争いが混じっている。6 にかける
   - 割れている文が残らず、語の当て方で何も変わらない　ただの言葉の争い。添え字を付けたまま本題に進む
   - 割れている文が残らず、語の当て方で決まりの結果や暮らしが変わる　言葉が大事な言葉の争い。「この語を、この目的のためにどう使うのがよいか」という別の問いとして立て直す
   - 禁じても、ほぼ同じ意味の語でしか言い直せない　岩盤の争いの候補。6 にかける

6. 価値の文と岩盤の候補を確かめる
   チャーマーズは、岩盤の札はめったに切れず、岩盤という見立てはほとんどいつも暫定で異論が残る、としている。彼が岩盤の候補に挙げる「べき」は、道徳や認識にかかわるものの一部に限られる。彼の確かめ方は、何が争点かを説明する、より基礎の文が見つかるかどうか。この手順では、その前に「べき」の実用の意味を外す。次の順に確かめる。
   - 「べき」「ねばならない」「よい」が残っていたら、目的と事実（今の制度、手順、相手の都合など）で言い直せる実用の意味かを確かめる。目的、制度、手順の言葉それぞれで試し、言い直せれば、割れるとしてもその事実をめぐる争いになるので 2 に戻る
   - 何が争点かを説明する文を、鍵の語も類語も使わずに両者に言ってもらう。出てきた文で両者が割れていれば、それが実質の争いの争点。事実の文なら 2 に戻る。価値の文なら、次に確かめることには両者が何を優先しているかを書く
   - 出てくるのが近い語の文だけ　岩盤の争いの候補。見立てとして返し、両者の立場の違いをそのまま書き留める

## 返す形

短く、次の順で返す。

- 争いの一文
- 両者が一致している事実（割れている事実があれば、何を確かめれば決着するかも）
- 禁じた語
- 言い直した文（添え字を使ったなら X1、X2 の中身）
- 振り分けと、その理由を一、二文
- 次に確かめるか決めるとよいことを一つ

診断は見立てとして示す。語の使い方をどちらにするかの選びは、ユーザーに返す。

## 確かめること

- 言い直しの文は、禁じた語の意味を抜いた言葉と、添え字を付けた語だけで書く。書いたあと一度読み返し、言い換えで同じ争いが続いていないかを確かめる
- 言い直した文が「もとの争いの一部」と言えるかには判断が入る。迷ったら、その文が片づいたらもとの争いも動くか、で確かめる
- 一つの争いには、事実の部分と言葉の部分が混じっていることが多い。部分ごとに振り分ける
- 同じ文でも、両者がどこまで一致しているかで、言葉の争いにも事実の争いにもなる。2 は毎回行う

## 例（返す形の見本）

「この夏は全然休んでいない」「毎週末、ベランダで本を読んでのんびりしているじゃない」

- 争いの一文　この夏に休みを取ったと言えるかで、二人が割れている
- 一致している事実　週末にベランダで本を読んでいる。旅行や遠出はしていない
- 禁じた語　休む、休み、くつろぐ、のんびり、ゆっくり
- 言い直し　休み1 は旅行や遠出で暮らしの場を離れること、休み2 は用事を入れずに好きなことをして過ごす時間。休み1 は取っていないが、休み2 は毎週取っている。両者ともうなずける
- 振り分け　ただの言葉の争い。休み1 についても休み2 についても、二人の言うことは食い違っていない。何かが左右されるなら（家の決まりで「休みの日」に家事当番が外れる、など）、言葉が大事な言葉の争いになり、どちらの意味で決まりを読むかを目的から決める問いが残る
- 次に確かめること　「休み」という語に掛かっている決まりや約束が、二人のあいだにあるか
