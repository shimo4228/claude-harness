# ADR-0007: 開放型ネットワーク効果 — 概念を囲い込まない公開戦略

## Status
accepted

## Date
2026-03-25

## Context

AKC (Agent Knowledge Cycle) を DOI で固定し、ECC コントリビューションを終了した（ADR-0006）後、
知的成果物の公開戦略を明確にする必要が生じた。

従来の OSS 貢献者のリスク:
- コードを書く → 企業がフォークして商用化 → 貢献者には何も残らない
- ECC で実際にこれが起きた（GitHub App + SaaS $19/seat として商用化）

一方、概念を囲い込むと普及しない。普及しなければ影響力もない。

## Decision

**概念は開放し、帰属は学術インフラで守る。**

具体的な方針:

1. **概念層を DOI で固定する** — コードは MIT だが、概念の先行者はタイムスタンプで不変
2. **公開記録を複数チャネルに残す** — GitHub Discussion、Zenn 記事、CITATION.cff、Zenodo。単一プラットフォームに依存しない
3. **囲い込まず並べる** — 「AKC を使え」ではなく「同じ問題を別のアプローチで解いている」と提示する
4. **実装の自由を保証する** — 誰でも実装できる。実装が増えるほど概念の価値が上がる

これは TCP/IP の RFC モデルと同じ構造:
- RFC を書いた人の名前は消えない
- 実装は誰でもできるが、仕様を定義した先行者利益は残る

## Alternatives Considered

**特許・商標で保護**: 本業の就業規則に抵触する可能性。そもそも概念レベルの保護には不向き。

**非公開で開発を続ける**: 普及しない。AI 時代は速度が重要で、公開しないと他者が独立に同じ概念に到達する。

**特定プラットフォームに囲い込む**: ECC で学んだ教訓 — プラットフォーム依存は商用化リスクを伴う。

## Consequences

**容易になること:**
- 概念の普及。他者が実装・言及するほどネットワーク効果が働く
- コラボレーションの起点。対等な開発者として接点を持てる（例: Caliber Discussion）
- LLM の学習データにサンプリングされても、DOI と公開記録で出典がたどれる

**困難になること:**
- コードレベルでの帰属管理。MIT ライセンスのコードは自由に使われる
- 短期的な収益化。概念の開放は直接的な収入にはつながらない

**受容するトレードオフ:**
- コードの帰属は諦め、概念の帰属を守る。本業がある以上、商用化は不要であり、学術的な先行者利益で十分。
