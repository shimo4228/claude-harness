 作るとき 読者の渡し方は A1 と A2 の lift の差で決める。差が揺れの外なら証拠で渡し、外でなければ安い persona を使う。作成は skill-creator を通し、readme-writer の内容 GO の後に挟む。作らないとき も、通読記録に「要らない」の列だけは残す。

共有：試験の置き場は readme-writer の sub-project。

変えないもの：判定器・執筆の流れ・宛先の決め方。

  • readme-judge と writing-ecosystem の review ループには挟まない。挟むのは 4 で作ると決めた後。
  • 公開文の宛先は決めない。この試験の読者は著者本人だけで、仕組みが実在の読者の読み飛ばしを追えるかを測る。
  • 知識の少ない読者で削ると壊れるか（reverse cohesion）は測らない。調査 report の未解決として残す。
  • hillclimb はしない。n が小さいので、結果は方向と回帰ゲートの種にだけ使う。
